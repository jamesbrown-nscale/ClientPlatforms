Applications

The apps on Windows and Mac devices that report to this site: what to put in each one's installer, how to install it, and the keys devices use. Create a key for each group of devices: it's shown once, so copy it into the installer then. A key never expires unless you give it a date, and you can expire it at any time to cut those devices off at once. Keys set on the server (ENROLLMENT_KEY, ELEVATION_INGEST_KEYS, RESTART_INGEST_KEYS) still work and are listed too.
